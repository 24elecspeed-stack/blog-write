24elecspeed.com + GitHub 설치 순서

키워드 리서치 앱의 라이선스 잠금 기능을 실제로 작동시키기 위한 4단계입니다. 순서대로 진행하고, 각 단계를 마치면 체크해서 어디까지 했는지 기억해두세요 (이 페이지에만 저장되며 다시 열어도 유지됩니다).

1

PHP 파일을 24elecspeed.com에 업로드

cPanel 파일 관리자 또는 FTP · license-server 폴더의 6개 파일

✓

D:\keyword\license-server\ 폴더에 있는 파일 6개를 호스팅의 /license/ 폴더를 새로 만들어 그 안에 업로드합니다 (워드프레스가 있는 폴더와 같은 위치에, license라는 이름의 새 하위 폴더).

파일역할
db.phpDB 연결 정보 (업로드 전에 꼭 편집)
schema.sql테이블 생성용 SQL (phpMyAdmin에서 실행, 업로드 안 해도 됨)
activate.php앱이 키를 처음 등록할 때 호출
check.php앱이 실행될 때마다 재확인할 때 호출
admin.php브라우저로 여는 키 관리 화면
generate.php(선택) URL로 키 생성 — admin.php로 충분하면 안 올려도 됨
업로드 전에 db.php를 메모장으로 열어 아래 네 값을 채워주세요.
define('LICENSE_DB_HOST', 'localhost');
define('LICENSE_DB_NAME', '여기에_DB이름');
define('LICENSE_DB_USER', '여기에_DB사용자');
define('LICENSE_DB_PASS', '여기에_DB비밀번호');
define('LICENSE_ADMIN_SECRET', '여기에_직접_정한_관리자_비밀번호');

LICENSE_ADMIN_SECRET은 나중에 admin.php 로그인 비밀번호로 그대로 씁니다 — 추측하기 어려운 값으로 직접 정해주세요.

2

MySQL 데이터베이스 만들고 테이블 생성

cPanel → MySQL 데이터베이스 / phpMyAdmin

✓
  1. cPanel의 "MySQL 데이터베이스"에서 새 데이터베이스와 사용자를 만들고, 사용자에게 전체 권한을 줍니다. (이미 워드프레스용 DB가 있다면 새로 안 만들고 그걸 그대로 써도 됩니다 — 테이블 이름이 license_keys라 워드프레스 테이블과 겹치지 않습니다.)
  2. 만든 DB 이름·사용자·비밀번호를 1단계의 db.php에 넣습니다.
  3. phpMyAdmin을 열어 그 데이터베이스를 선택하고, "SQL" 탭에 schema.sql의 내용을 붙여넣어 실행합니다.
CREATE TABLE IF NOT EXISTS license_keys (
    id INT AUTO_INCREMENT PRIMARY KEY,
    license_key VARCHAR(64) NOT NULL UNIQUE,
    device_id VARCHAR(128) NULL,
    note VARCHAR(255) NULL,
    activated_at DATETIME NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

실행 후 왼쪽 테이블 목록에 license_keys가 보이면 성공입니다.

3

GitHub 저장소 — 중계 파일 올리기

github.com · 공개 저장소 1개, 파일 1개

✓

앱이 실행될 때마다 제일 먼저 확인하는 작은 신호등 파일입니다. 이 파일이 실제 서버 주소를 알려주고, 서비스 전체를 껐다 켰다 할 수 있는 스위치 역할도 합니다.

  1. GitHub에서 새 저장소를 만듭니다 (이름은 자유, Public으로 설정).
  2. 그 저장소에 license-status.json 파일을 하나 만들고 아래 내용을 붙여넣습니다.
  3. 파일 페이지에서 Raw 버튼을 눌러 나오는 주소(https://raw.githubusercontent.com/...)를 복사해둡니다.
{
  "service_enabled": true,
  "api_base": "https://24elecspeed.com/license"
}
서비스를 전체적으로 잠깐 멈추고 싶을 때는, 이 파일의 service_enabled를 false로 바꿔 저장하기만 하면 모든 기기의 앱이 즉시 막힙니다. 다시 true로 바꾸면 즉시 풀립니다.
4

앱에 GitHub 주소 연결하고 다시 빌드

3단계에서 복사한 raw 주소를 알려주세요

✓

3단계에서 복사한 raw 링크를 채팅으로 보내주시면, LicenseGate.kt의 아래 자리표시자를 그 주소로 바꿔서 최종 버전을 다시 빌드해드립니다.

private const val RELAY_URL =
    "https://raw.githubusercontent.com/여기에_깃헙아이디/여기에_저장소이름/main/license-status.json"

이 작업이 끝나면 키입력 버전이 실제로 인증되기 시작합니다.

참고 — 키 발급·관리 (admin.php)

https://24elecspeed.com/license/admin.php를 폰이나 PC 브라우저로 열고, LICENSE_ADMIN_SECRET으로 로그인합니다.
